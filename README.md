# Matilde — independent portfolio

This is a lightweight static version inspired by the supplied Pixpa screenshots.
It does not depend on Pixpa.

## Publish for free with GitHub Pages

1. Create a free GitHub account at https://github.com/
2. Create a new **public** repository, e.g. `matilde-portfolio`.
3. Upload everything inside this folder (index.html, styles.css, script.js and the `assets` folder).
4. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
5. GitHub will give you a free `github.io` address.

## Customize

- Replace the images in `assets/` with the original full-resolution photographs.
- Replace the `href="#"` social links with the real profile URLs.
- Replace the empty `mailto:` link with the preferred email address.
- Add the remaining travel photographs to the placeholder sections.

The supplied screenshots were used as visual references. Because only screenshots were available, the included photographs are crops of the images visible in those screenshots rather than the original full-resolution files.
